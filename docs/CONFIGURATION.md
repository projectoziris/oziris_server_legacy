# Configuration

## Central configuration: `config\server.ini`

All modules read this file. Keys are read by `scripts\common.cmd` and exposed to
every script. Do not add spaces around `=`. Lines starting with `;` are comments.

| Key | Default | Meaning |
|-----|---------|---------|
| `install_path` | `C:\OZI-RIS-Server` | Target installation directory |
| `apache_port` | `80` | Apache HTTP listen port |
| `mysql_port` | `3306` | MariaDB listen port |
| `db_root_pass` | `oziris-root` | MariaDB root password (set on install) |
| `db_name` | `oziris` | Application database name |
| `db_user` | `oziris` | Application database user |
| `db_pass` | `oziris-app` | Application database password |
| `memory_limit` | `256M` | PHP `memory_limit` |
| `upload_max_size` | `128M` | PHP `upload_max_filesize` |
| `timezone` | `Asia/Jakarta` | PHP `date.timezone` |
| `backup_retention` | `7` | Days of backups to keep |

Passwords must avoid the characters `!`, `%`, `&`, `"` and spaces.

Changing a value after install:

- **Ports / passwords / paths**: edit `server.ini`, then re-run the affected module
  install script (or `installer\install.cmd` — already-installed components are
  skipped and their configuration is regenerated).
- **PHP settings**: edit `server.ini`, then run `scripts\configure_php.cmd`.

## Generated per-component configuration

| Component | File | Generated by |
|-----------|------|--------------|
| Apache | `<install>\apache24\conf\httpd.conf` | `install_apache.cmd` |
| Apache | `<install>\apache24\conf\vhost.conf` | `install_apache.cmd` |
| Apache+PHP | `<install>\apache24\conf\extra\php.conf` | `configure_php.cmd` |
| PHP | `<install>\php54\php.ini` | `configure_php.cmd` |
| MariaDB | `<install>\mariadb\my.ini` | `install_mariadb.cmd` |
| phpMyAdmin | `<install>\phpmyadmin\config.inc.php` | `deploy_phpmyadmin.cmd` |

The templates live in `config\` and are expanded at install time by
`scripts\lib\Expand-Config.ps1` (placeholders `@@NAME@@`).

## Enabled PHP extensions

`mysqli`, `gd`, `openssl`, `curl`, `mbstring`, `fileinfo` (plus `pdo_mysql`).
PHP error display is disabled; errors are logged to `<install>\php54\logs\php-error.log`.

## Security defaults

- Apache `ServerTokens Prod`, directory listing locked down, `Options` minimal.
- PHP `expose_php Off`, `display_errors Off`, `log_errors On`.
- MariaDB: anonymous accounts and the `test` database removed, app user scoped to
  the application database only, no default passwords (values come from `server.ini`).
- phpMyAdmin: cookie auth, server bound to `127.0.0.1`, sample config removed.
